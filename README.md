## Deskripsi Proyek

Proyek ini membahas pemodelan data pariwisata di Kota Yogyakarta menggunakan _Resource Description Framework_ (RDF) dalam format RDF/XML. Data disusun untuk merepresentasikan objek wisata beserta informasi yang berkaitan, seperti lokasi, kategori wisata, pengelola, fasilitas, jam operasional, dan deskripsi.

## Tujuan

1. Menerapkan konsep Web Semantik dalam pemodelan data pariwisata.
2. Mengidentifikasi resource utama dan resource pendukung beserta URI masing-masing.
3. Merepresentasikan hubungan antarresource menggunakan RDF Triple.
4. Menyusun data dalam format RDF/XML.
5. Menampilkan informasi pariwisata melalui website berbasis data RDF.

## Objek Wisata

Objek wisata yang dimodelkan dalam proyek ini meliputi:

1. Malioboro
2. Keraton Yogyakarta
3. Taman Sari
4. Alun-Alun Kidul
5. Museum Sonobudoyo
6. Gembira Loka Zoo
7. Taman Pintar Yogyakarta

## Teknologi dan Format Data

- **RDF:** Representasi resource dan hubungan antarresource.
- **RDF/XML:** Format serialisasi data RDF berbasis XML.
- **PHP:** Membaca dan memproses data RDF/XML untuk ditampilkan pada website.
- **HTML:** Menyusun struktur halaman website.
- **CSS:** Mengatur tampilan dan tata letak website.

## Struktur Proyek

```text
.
├── index.php
├── style.css
├── Pariwisata_Kota_Yogyakarta.rdf
└── README.md
```

Keterangan:

- `index.php`: Halaman utama untuk membaca dan menampilkan data pariwisata.
- `style.css`: File untuk mengatur tampilan website.
- `Pariwisata_Kota_Yogyakarta.rdf`: Data pariwisata dalam format RDF/XML.
- `README.md`: Dokumentasi proyek.
